# module01_enviroment
LR2

1. Название и цель
   
   Название: Лабораторная работа №1. Colab/Jupyter: порядок выполнения ячеек, его влияние на runtime.
   Цель: Изучить влияние порядка выполнения ячеек на runtime, научиться восстанавливать правильный порядок и проверять работоспособность notebook после перезапуска.
   
2. Состав файлов
   
   ЛР01_Кованева_ФиПЛ_1курс_1группа_2уровень.ipynb — содержит все задания, ответы на retrieval quiz, демонстрационные ошибки, исправления, таблицу состояния и раздел      «Как проверить».
   
3. Как открыть
   
   Откройте файл ЛР01_Кованева_ФиПЛ_1курс_1группа_2уровень.ipynb в Jupyter Notebook или Google Colab.
   Для проверки выполните Restart runtime, затем Run all. В файле намеренно допущены ошибки (неправильный порядок ячеек) для демонстрации NameError.
   
4. Проверка
 
    После перезапуска runtime и последовательно правильного выполнения ячеек ошибок NameError не возникает, а выводы совпадают с ожидаемыми
   
5. Ограничения

   Проверка не включает автоматические тесты: правильность оценивается вручную по выводам.
